# A walkthrough proves the game is completable by somebody who already
# knows the answer. This file proves something different and, for a
# player, more important: that somebody who does NOT know the answer,
# who pokes at the world with plausible-but-wrong commands, still gets
# carried into the game rather than stranded at the entrance.
#
# Every line here is what a real player types before they have a model
# of the world: wrong nouns, wrong verbs, sightseeing, and the four or
# five things everybody tries in a text adventure (LOOK, INVENTORY,
# EXAMINE ME, XYZZY). Roughly half do not parse.
#
# The bar this file sets, asserted by verify.mjs:
#   - must reach the Hall of Doors, i.e. get down the rabbit-hole and
#     through the passage without ever being told the right command
#   - must never end the game
#   - must never print a Zork-voiced default (see verify.mjs list)
#
# Wonderland should pass this more easily than its siblings: the design
# is deliberately forgiving, no move is fatal, and the only genuinely
# required action in Act 1 is going down a hole that the room now names.
